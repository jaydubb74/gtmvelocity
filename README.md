# GTM Velocity+

> Your people, powered up.

Website for [gtmvelocity.ai](https://gtmvelocity.ai) a business focused on AI-powered efficiency for GTM teams.

## Stack

- **Frontend:** Single-page HTML/CSS — no framework, no build step
- **Hosting:** Cloudflare Workers (Static Assets)
- **Deployment:** Auto-deploys on push to `main` via Cloudflare Pages CI
- **Domain:** `gtmvelocity.ai` via Cloudflare Registrar

## Local Development

No dependencies. Just open the file:

```bash
open index.html
```

## Deployment

Any push to `main` triggers an automatic deploy via Cloudflare. The live site is available at:

- **Production:** https://gtmvelocity.ai
- **Workers dev:** https://gtmvelocity.joshwetzel.workers.dev
